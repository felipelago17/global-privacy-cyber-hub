# Paper summaries

Short-form summaries (one screen or less) of source documents. Full analyses with practical implications and critique live in [`../../../analyses/`](../../../analyses/); this folder is for quick-reference abstracts of papers that have not yet earned a full analysis, or for one-page digests of long reports.

Template:

```markdown
# <Title> — <Author / organisation> (<date>)

`<Jurisdiction> · <Sector> · <Framework>`

**Source:** <link>

**In one paragraph:** ...

**Three things to remember:**
1. ...
2. ...
3. ...

**Related analysis:** <link or "none yet">
```

Current full analyses are indexed in [`../links.md`](../links.md).
