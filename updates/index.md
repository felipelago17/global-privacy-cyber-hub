# Daily updates

Automated daily digest of privacy, cybersecurity and AI-governance developments from regulators, standards bodies and trusted practitioner sources (IAPP, FPF, EDPB, ICO, CNIL, ENISA, NCSC, FTC, NIST, CISA, EFF, Cyber Security News — some via Google News site-feeds where the regulator blocks automated access). Each item is reported once, on the day it is first seen. Sources and filters are defined in [`tools/fetch_updates.py`](https://github.com/felipelago17/global-privacy-cyber-hub/blob/main/tools/fetch_updates.py).
